# الموقع الشخصي - اسراء الهتاري

موقع شخصي ثابت (HTML + CSS) يعرض:

- الاسم
- نبذة من 3 أسطر
- خمس مهارات
- وسيلة التواصل (البريد الإلكتروني)

## الملفات

- `index.html`: صفحة الموقع كاملة (التنسيق داخل الملف نفسه).
- `README.md`: هذا الملف.

## التشغيل محليًا

افتحي `index.html` في أي متصفح.

## النشر

يُرفع المشروع على GitHub ثم يُنشر عبر Cloudflare Pages
(لا يحتاج أمر بناء، ومجلد الإخراج هو المجلد الرئيسي).
